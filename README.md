# dendrometer-logger
The aim of this project is to measure and record stem-diurnal-variations in different plants., and help understand water-regulation strategies and other aspects of plant physiology using dendrometry. The data is recorded as real-time measurements of plant stem width, which simultaneously logs the data online and offline for research use. This was developed by Aabhas Senapati with members of Treehouse Lab - IIT Bombay, during the Summer of 2026, through the support of a community engagement grant from Harvey Mudd College. This repository has the code and the required code and pin mapping table of the design of this project and to be replicated by anyone willing to do so.
